1. Requisitos e instalação

  • Python 3.9 ou superior (testado com 3.11).
  • Pacotes obrigatórios: numpy, scipy, matplotlib.
  • Pacote opcional: pandas (análise dos CSVs) e pytest (testes).

2. Estrutura do projeto

single_wiebe/
├── single_wiebe.py      # biblioteca: geometria, Wiebe, Hohenberg, EDOs, PSO, DE, plots, export
├── run_model.py         # script principal (CLI): valida → calibra → plota → exporta
├── requirements.txt
├── README.md            # documentação detalhada (física, unidades, diferenças Mathematica×SciPy)
├── Help.html            # este arquivo de ajuda

└── tests/
    └── test_model.py    # 15 testes (geometria, Wiebe, dados, validação 409.385 kPa)
ArquivoO que faz
single_wiebe.py Biblioteca. Contém load_experimental, simulate_model, calibrate_pso (compatível com o notebook), calibrate_de (alternativo), simulate_full, make_plots e as exportações.
run_model.py Orquestra tudo pela linha de comando. Não precisa importar nada manualmente.
results/ Criada automaticamente na primeira execução.

3. Início rápido

Um único comando roda o fluxo completo — validação do caso de referência do notebook, calibração por PSO (compatível com o Mathematica), calibração alternativa por differential evolution, os 9 gráficos e os 2 CSVs:

python run_model.py
✔ Resultado esperado (≈ 15 min):
  • Validação: erro = 409.385649 kPa (referência do notebook: 409.385 kPa, Δ ≈ +0.00016%);
  • PSO (seed 42): erro ≈ 63.8468 kPa em ~150 iterações (~2 min);
  • DE: mesmo ótimo ≈ 63.8468 kPa (~13 min);
  • 9 PNGs + 2 CSVs em results/.

Execuções mais rápidas:

python run_model.py --skip-de      # só validação + PSO  (~3 min)
python run_model.py --skip-pso     # só validação + DE
python run_model.py --skip-pso --skip-de   # só validação (~2 s)

4. Casos de uso passo a passo

4.1 — Reproduzir o caso de validação do notebook essencial

Reproduz o erro 409.385 kPa para Rc=17, m=0.504, θ₀=−6.54°, Δθ=62°:

python run_model.py --skip-pso --skip-de

ou, programaticamente:

import numpy as np
import single_wiebe as sw

data = sw.load_experimental("../P_exp-Carga-3_45%.txt")
erro, P_sim, Tg_sim, Qp_sim = sw.simulate_model(
    Rc=17.0, m=0.504,
    theta0=np.radians(-6.54), delta_theta=np.radians(62.0),
    theta_exp=data["theta"], pressure_exp=data["pressure"],
)
print(erro)   # 409.385649...

4.2 — Calibrar Rc, m, θ₀ e Δθ

# PSO compatível com o notebook (20 partículas, beta=2, até 800 iterações)
python run_model.py --seed 42 --skip-de

# Método alternativo robusto (SciPy differential_evolution)
python run_model.py --seed 42 --skip-pso

O PSO é estocástico: mudar --seed muda a trajetória, mas o erro converge para ≈ 63.85 kPa e o ótimo tende à borda do domínio (θ₀ = 2°, Δθ = 40°), como no Mathematica (referência: erro 63.8473 kPa com Rc=15.8686, m=0.524544).

4.3 — Gerar gráficos e CSVs com parâmetros próprios

import numpy as np
import single_wiebe as sw

data = sw.load_experimental("../P_exp-Carga-3_45%.txt")
res = sw.simulate_full(
    Rc=16.0, m=0.55,
    theta0=np.radians(0.0), delta_theta=np.radians(50.0),
    theta_exp=data["theta"], pressure_exp=data["pressure"],
)
print("erro =", res.erro, "kPa")
sw.make_plots(res, outdir="results", data=data)  # 9 PNGs
sw.export_csv(res, outdir="results")          # CSV principal
sw.export_pressure_degrees_bar(               # grade em graus/bar (~0.34°)
    16.0, 0.55, np.radians(0.0), np.radians(50.0),
    theta_i=data["theta"][0], theta_f=data["theta"][-1],
    P1=data["P1"], outdir="results",
)

4.4 — Verificar a qualidade dos dados carregados

data = sw.load_experimental("../P_exp-Carga-3_45%.txt")
print(data["n_total"])      # 503 linhas do arquivo
print(data["n_filtered"])   # 459 após o filtro -2 ≤ θ ≤ 2 rad
print(data["theta_i"], data["theta_f"])  # -1.998401994  1.998401994 rad
print(data["P1"])           # 138.2 kPa (pressão no IVC)

Se as contagens divergirem de 503/459, a função levanta ValueError — isso protege contra arquivos errados.

5. Referência da linha de comando (run_model.py)

OpçãoPadrãoDescrição
--data CAMINHO ..\P_exp-Carga-3_45%.txt Arquivo experimental (colunas: θ [rad], P [bar]).
--seed N 42 Semente aleatória do PSO e do DE (reprodutibilidade).
--iters N 800 Sobrescreve o máximo de iterações do PSO.
--skip-pso — Não executa a calibração PSO.
--skip-de — Não executa o differential evolution.
--outdir PASTA results/ Diretório de saída dos gráficos e CSVs.
--quiet — Suprime o log iteração-a-iteração do PSO.

Exemplos combinados

# varredura de sementes só com PSO
python run_model.py --skip-de --seed 1
python run_model.py --skip-de --seed 2 --quiet
python run_model.py --skip-de --seed 3 --quiet

# dados em outra pasta
python run_model.py --data "C:\dados\P_exp-Carga-3_45%.txt"

6. Uso como biblioteca (single_wiebe.py)

FunçãoAssinaturaRetorno
load_experimental (path) dict com theta (rad), pressure (kPa), P1, theta_i, theta_f e contagens.
simulate_model (Rc, m, theta0, delta_theta, theta_exp, pressure_exp) (erro, P_sim, Tg_sim, Qp_sim). Em caso de falha: (1e10, None, None, None) (penalidade, sem exceção).
simulate_full mesmos parâmetros ModelResult com x_b, dQ_dtheta e tudo pronto para plots/export.
calibrate_pso (theta_exp, pressure_exp, seed=..., ...) dict com params, erro, history e sinalização de parada por repetição.
calibrate_de (theta_exp, pressure_exp, seed=...) dict análogo, via scipy.optimize.differential_evolution.
burned_fraction (theta, theta0, delta_theta, m) (x_b, dx_b/dtheta) — modo compatibilidade (sem truncamento).
compute_error (P_exp, P_sim) sqrt(SSres/(q−2)) — definição do notebook.

8. Testes

python -m pytest tests/ -v        # recomendado
python tests/test_model.py        # alternativa sem pytest

15 testes cobrem: leitura dos 503/459 pontos, geometria (PMS/PMI, derivada analítica × numérica), Wiebe (guarda em θ<θ₀, derivada, não-truncamento), dimensões e NaN das saídas, condições iniciais, o caso de validação 409.385 kPa e a penalidade para parâmetros não físicos.

9. Solução de problemas

SintomaCausa provávelSolução
ValueError: Esperadas 503 observações… Arquivo de dados errado ou modificado. Conferir --data; usar o arquivo original.
Validação não dá 409.385 kPa Dados/tolerâncias alterados. Ver README.md (seção "Diferenças esperadas"); tolerâncias em RTOL/ATOL_DEFAULT.
PSO lento (>5 min) 800 iterações × 20 partículas. Normal; costuma parar antes (~150 it.) por estagnação. Reduza com --iters 300.
erro = 10000000000.0 Parâmetros não físicos → integração falhou. Esperado (penalidade); a otimização continua.
ModuleNotFoundError: single_wiebe Rodando de fora da pasta do pacote. cd single_wiebe antes, ou adicione a pasta ao PYTHONPATH.
Caracteres acentuados estranhos no console Código de página do Windows (cp1252). set PYTHONIOENCODING=utf-8 (cmd) ou $env:PYTHONIOENCODING="utf-8" (PowerShell).
Matplotlib não abre janelas Por design usa backend Agg. Os gráficos são salvos em results/ — abra os PNGs.

Perguntas frequentes

Por que o divisor do erro é q − 2?
É a definição exata do notebook (Sqrt[SSres/(q−2.)]), mesmo com 4 parâmetros ajustados. Mantida por fidelidade — ver comentário em compute_error.

Posso interpolar a solução?
Não é necessário: solve_ivp(t_eval=theta_exp) já devolve a solução exatamente nos ângulos experimentais.

Como rodar em Jupyter?
from single_wiebe import * com o notebook na pasta single_wiebe/, ou instale o pacote no sys.path. Depois siga os exemplos da seção 6.
